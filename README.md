# Baby Shower - Gabriel y Diana

Invitación web responsiva para confirmar asistencia por WhatsApp.

## Archivos

- `index.html`: contenido de la invitación y formulario RSVP.
- `styles.css`: estilos y diseño responsivo.
- `script.js`: generación del mensaje de confirmación de WhatsApp.
- `babyshower.jpg`: imagen de fondo de la tarjeta y miniatura para compartir.

## Publicar en Cloudflare Pages

1. En Cloudflare, crea un proyecto de Pages conectado al repositorio de GitHub.
2. Selecciona la rama `main`.
3. Elige **None** como framework.
4. Deja vacío el comando de compilación y usa `.` como directorio de salida.
5. Guarda la configuración para iniciar el despliegue.
